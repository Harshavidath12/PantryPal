# PantryPal

A smarter home for fresher tomorrows. PantryPal helps you track your groceries, manage expiration dates, reduce food waste, and automatically generate smart shopping lists.

## 🔗 Repository Link
**GitHub Repository:** [https://github.com/Harshavidath12/PantryPal](https://github.com/Harshavidath12/PantryPal)

## 📦 Installable Build (APK)
An installable Android Package Kit (APK) can be generated by following the build instructions below. 
Once built, the `.apk` file can be found in the following directory:
`app/build/outputs/apk/debug/app-debug.apk`

*You can transfer this file to any Android device (Android 8.0+) to install the application manually. Ensure "Install from Unknown Sources" is enabled on your device.*

---

## 🛠️ How to Build and Run the App

### Prerequisites
- **Android Studio** (Koala or newer recommended)
- **Java Development Kit (JDK)** 17 or higher
- **Android SDK** (API 34)

### Option 1: Running via Android Studio (Recommended)
1. Open Android Studio.
2. Select **File > Open** and choose the `PantryPal` folder.
3. Allow Gradle to finish syncing the project dependencies.
4. Connect a physical Android device via USB (with USB Debugging enabled) or start an Android Emulator.
5. Click the **Run** button (green play icon) in the top toolbar, or press `Shift + F10`.
6. The app will compile and launch automatically on your device.

### Option 2: Building via Command Line
If you prefer to build the project without opening Android Studio, you can use the Gradle wrapper from your terminal.

1. Open your terminal / command prompt.
2. Navigate to the project root directory:
   ```bash
   cd path/to/PantryPal
   ```
3. Run the following command to assemble the debug APK:
   - **On Windows:**
     ```bash
     gradlew.bat assembleDebug
     ```
   - **On Mac/Linux:**
     ```bash
     ./gradlew assembleDebug
     ```
4. Once the build finishes, locate your APK at `app/build/outputs/apk/debug/app-debug.apk`.
